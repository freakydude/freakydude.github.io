Flash the BTT Manta M8P and EBB42 with Klipper Using Katapult

This is a quick and dirty guide, mostly for my own purposes, on how to flash the BTT Manta M8P CAN and the EBB42 board with Klipper using Katapult. The process should work for other BTT Manta M8P and EBB versions too, but you have to adjust the configuration accordingly. The BTT Manta M8P CAN board can be flashed and used with Klipper via two different methods: a USB connection or CAN bus. If you are using toolhead boards that support CAN bus, like the EBB36 or EBB42, you have to use CAN bus for the communication between the mainboard and the toolhead board. Flash Armbian onto the BigTreeTech CB1 eMMC Compute Module

This step-by-step guide explains how to flash Armbian Linux onto the BigTreeTech CB1 eMMC compute module. I describe the process for a Windows machine, but the steps are very similar for Linux users. The eMMC version of the CB1 has built-in storage, which makes the process slightly more complicated than flashing an SD card for the non-eMMC versions. Requirements You will need the following items to complete the process. Hardware A BigTreeTech RPI adapter or a BigTreeTech Manta board to provide the necessary USB and LAN connectors. A USB-C cable to connect and power the CB1 from your Windows machine. For added reliability, I recommend putting a USB hub with a dedicated power adapter in between. Software A universal USB driver. See Zadig. Allwinner tools to switch the CB1 into USB device mode. See sunxi-tools or the sunxi wiki. An Armbian Linux image of your choice. See Armbian for CB1. An image flashing tool.
